# Práctica de Programación 2 - Java

Este repositorio está destinado a ir acumulando soluciones a ejercicios prácticos de la materia Programación 2 de la TUP, desarrollados en lenguaje Java.

## Objetivo

El propósito de este proyecto es documentar y organizar cada ejercicio resuelto a medida que se avanza en la cursada, reforzando conceptos de programación orientada a objetos, estructuras de datos, lógica de negocio y resolución de problemas.

## Estructura

El contenido del repositorio se irá incrementando progresivamente con nuevas carpetas y soluciones, cada una correspondiente a un ejercicio o práctica específica.

## Progresión de dificultad

Los ejercicios se irán agregando con un nivel de dificultad creciente, comenzando por problemas básicos y avanzando hacia desafíos más complejos a medida que se profundicen los temas de la materia.

## Tecnologías

- Java
- Programación orientada a objetos
- Ejercicios prácticos de la materia Programación 2

## Estado del repositorio

Este repositorio se encuentra en desarrollo continuo. Cada nueva entrega o ejercicio resuelto será agregado con el objetivo de mantener un registro ordenado del aprendizaje y de la evolución en la resolución de problemas.

## Uso

Cada carpeta dentro del proyecto representa una práctica o ejercicio, y se puede abrir y ejecutar de forma independiente según corresponda.
